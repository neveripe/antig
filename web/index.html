📖 How to copy your CSV file:

  1. Find your CSV file in File Explorer
  2. Right-click on the file
  3. Choose "Open with" → "Notepad"
  4. Press Ctrl + A to select all text
  5. Press Ctrl + C to copy
  6. Come back here and paste into the box below with Ctrl + V
  1. Find your CSV file in Finder
  2. Right-click (or Control-click) on the file
  3. Choose "Open With" → "TextEdit"
  4. Press ⌘ Cmd + A to select all text
  5. Press ⌘ Cmd + C to copy
  6. Come back here and paste into the box below with ⌘ Cmd + V
ℹ️ Processing may take a few moments for large files (10,000+ rows). Your computer is doing all the work locally - no data is sent anywhere!
